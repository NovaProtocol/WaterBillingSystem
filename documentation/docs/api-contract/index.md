# API Contract

## Overview

The BillServer REST API is organized around standard HTTP methods and JSON responses. It is consumed primarily by the MeterReadingApp for reading sync and customer data retrieval.

**Base URL**: `http://<server>:5005/api`

## Authentication

API keys are generated by staff from the Meter Reading page (`/staff/meter-reading`).

**Format**: `CRDC-` + 32 uppercase hex characters

| Method | Example |
|---|---|
| **Bearer Token** | `Authorization: Bearer CRDC-A1B2C3D4E5F67890A1B2C3D4E5F67890` |
| **Query Parameter** | `?api_key=CRDC-A1B2C3D4E5F67890A1B2C3D4E5F67890` |
| **Session Cookie** | Flask-Login session (only for `/api/customer/:num`) |

## Implemented Endpoints

| # | Method | Endpoint | Auth | Description |
|---|---|---|---|---|
| 1 | GET | `/api/health` | None | DB connectivity check |
| 2 | GET | `/api/key/info` | API key | API key + staff details |
| 3 | GET | `/api/customer/:customer_number` | API key or session | Full billing details |
| 4 | GET | `/api/customer/:customer_number/details` | API key | Profile + reading history |
| 5 | GET | `/api/readings/customer/:customer_number` | API key | Single customer + latest reading |
| 6 | POST | `/api/readings/sync` | API key | Bulk sync readings |
| 7 | POST | `/api/readings/upload` | API key | Upload single reading |
| 8 | GET | `/api/pricing` | API key | Pricing tiers (cached 1h) |
| 9 | GET | `/api/customers/changed` | API key | Changed customers since timestamp |
| 10 | GET | `/api/readings/bulk` | API key | Bulk data for multiple customers |
| 11 | GET | `/api/nfc/config` | API key | NFC_SECRET for offline password computation |
| 12 | POST | `/api/nfc/sync` | API key + can_enroll_customer | Upload NFC enrollments |
| 13 | GET | `/api/nfc/tags` | API key | All registered NFC tags |
| 14 | POST | `/api/nfc/clear` | API key + can_drop_reading | Clear NFC tag from a customer |

### 1. GET /api/health

Check database connectivity.

**Endpoint**: `<ServerURL>/api/health`

**Auth**: None

**Response** `200` — DB connected:
```json

```

**Response** `500` — DB unreachable:

### 6. POST /api/readings/sync

Upload multiple readings. Uses monthly duplicate check.

**Endpoint**: `<ServerURL>/api/readings/sync`

**Auth**: API key — `Authorization: Bearer <key>` header or `?api_key=<key>` query param

**Payload**:
```json
{
  "readings": [
    {"customer_number": "C1", "reading_value": 280.5},
    {"customer_number": "C2", "reading_value": 150.2, "timestamp": 1779000000}
  ]
}
```

**Response** `200` — partial success:
```json
{
  "synced": 1,
  "total": 2,
  "results": [
    {"index": 0, "reading_id": 42, "customer_number": "C1"}
  ],
  "errors": [
    {"index": 1, "error": "This meter has already been read this month"}
  ]
}
```

**Response** `200` — all accepted:
```json
{
  "synced": 2,
  "total": 2,
  "results": [
    {"index": 0, "reading_id": 42, "customer_number": "C1"},
    {"index": 1, "reading_id": 43, "customer_number": "C2"}
  ],
  "errors": []
}
```

**Response** `400` — missing required field:
```json
{"error": "Request body must contain a readings array"}
```

**Response** `401` — missing or invalid API key:
```json
{"error": "Authentication required"}
```

### 10. GET /api/readings/bulk?customer_numbers=C1,C2&limit=5

Bulk fetch for data sync. Response is keyed by customer number.

**Endpoint**: `<ServerURL>/api/readings/bulk`

**Auth**: API key — `Authorization: Bearer <key>` header or `?api_key=<key>` query param

**Query params**:

| Param | Type | Default | Description |
|---|---|---|---|
| `customer_numbers` | string | required | Comma-separated list |
| `limit` | int | `0` (no limit) | Max readings per customer |

**Response** `200` — customer data with reading history:
```json
{
  "customers": {
    "C1": {
      "customer": {
        "customer_number": "C1",
        "name": "Juan Dela Cruz",
        "address": "123 Rizal St., Brgy. San Jose",
        "contact_number": "09123456789",
        "phase": "Phase 1",
        "block": "Block A",
        "street": "Rose St",
        "x_coordinate": 14.6,
        "y_coordinate": 120.95,
        "nfc_uid": "045A6BC2DEF180"
      },
      "readings": [
        {"id": 480, "reading_value": 250.6, "reader": "Juan Dela Cruz", "timestamp": 1778968800}
      ]
    }
  }
}
```

`nfc_uid` is `null` if the customer has no registered NFC tag. The phone computes the PWD_AUTH password locally from `nfc_pwd_secret` + UID.

**Response** `400` — missing `customer_numbers` parameter:
```json
{"error": "customer_numbers parameter is required"}
```

**Response** `401` — missing or invalid API key:
```json
{"error": "Authentication required"}
```

```json
{"error": "Authentication required"}
```


## Billing Page Endpoints (Cookie-Auth)

| Method | Endpoint | Description |
|---|---|---|
| POST | `/billing/api/lookup` | Customer lookup with receipt verification |
| POST | `/billing/api/confirm` | Confirm identity, set cookies, redirect to `/billing/:num` |
| GET | `/billing/api/:num/readings?page=N&per_page=N` | Paginated readings |
| GET | `/billing/api/:num/payments?page=N&per_page=N` | Paginated payments |
| GET | `/billing/api/:num/history?page=N&per_page=N` | Paginated billing history |

These require a signed cookie (`customer_number` + `receipt_number`) set by the landing page confirmation flow.

### POST /billing/api/lookup

Look up a customer using their customer number and most recent receipt number.

**Endpoint**: `<ServerURL>/billing/api/lookup`

**Auth**: None (rate-limited to 10 requests per minute per IP)

**Payload**:
```json
{
  "customer_number": "C1",
  "last_receipt": "RCP-1712345678-ABCD"
}
```

**Response** `200` — customer found:
```json
{
  "customer_number": "C1",
  "name": "Juan Dela Cruz",
  "address": "123 Rizal St., Brgy. San Jose",
  "contact_number": "09123456789",
  "email": "juan.delacruz1@email.com",
  "x_coordinate": 14.6,
  "y_coordinate": 120.95,
  "cumulative_balance": 0.0
}
```

**Response** `400` — missing customer number:
```json
{"error": "Customer number is required"}
```

**Response** `403` — receipt mismatch:
```json
{"error": "Receipt number does not match our records"}
```

**Response** `404` — customer not found:
```json
{"error": "Customer not found"}
```

**Response** `429` — rate limited:
```json
{"error": "Too many requests. Please try again later."}
```

## Pricing Tiers Reference

| Tier | Range | Rate | Unit |
|---|---|---|---|
| First 10 m\u00b3 | 0\u201310 m\u00b3 | $150.00 | flat |
| 11 m\u00b3 to 20 m\u00b3 | 10\u201320 m\u00b3 | $25.00 | per m\u00b3 |
| 21 m\u00b3 to 30 m\u00b3 | 20\u201330 m\u00b3 | $30.00 | per m\u00b3 |
| 31 m\u00b3 to 40 m\u00b3 | 30\u201340 m\u00b3 | $35.00 | per m\u00b3 |
| 41 m\u00b3 and above | 40+ m\u00b3 | $40.00 | per m\u00b3 |

Late penalty: **$15.00** if unpaid after 7 days from reading date.

## Error Responses

All endpoints return errors as:
```json
{"error": "Description of what went wrong"}
```
